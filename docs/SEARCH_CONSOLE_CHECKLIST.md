# Google Search Console Checklist

1. https://goodmanseo.com/ 를 속성으로 추가합니다.
2. 도메인 속성 또는 URL 접두사 속성 중 하나를 선택해 소유권을 인증합니다.
3. `https://goodmanseo.com/sitemap.xml` 을 제출합니다.
4. 홈, 스타터 패키지, 블로그, 문의 페이지를 각각 URL 검사로 색인 요청합니다.
5. 블로그 상세 페이지도 개별적으로 색인 요청합니다.
6. `robots.txt` 가 `https://goodmanseo.com/robots.txt` 에서 정상 노출되는지 확인합니다.
7. 모바일 사용성, 페이지 색인, 핵심 웹 지표 보고서를 추후 체크합니다.
8. 새 글이나 페이지를 추가할 때는 sitemap.xml 도 함께 업데이트합니다.
