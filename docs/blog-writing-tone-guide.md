# 블로그 글쓰기 톤 가이드

Last updated: 2026-07-30

이 문서는 GoodmanSEO 블로그의 말투 기준입니다.
`customer-temperature-before-sales-review` 글을 교정하면서 확정한 규칙을 정리했습니다.

블로그 글을 새로 쓰거나 기존 글을 고칠 때 이 문서를 먼저 읽습니다.

---

## 한 줄 원칙

> **단정함이 기본, 온기는 양념.**

문장은 `~입니다`로 끝내고, 감정이 들어가는 대목에만 `~요`를 씁니다.
반대로 하면 어린애 달래는 말투가 되어 전문성이 떨어집니다.

---

## 목표 비율

| 어미 | 목표 | 비고 |
|---|---:|---|
| `~입니다` / `~합니다` | **30% 이상** | 기본 골격 |
| `~요` / `~어요` / `~예요` | **5% 내외** | 감정 대목에만 |
| 명사형 종결 | 자유 | 리듬 조절용 |

`~요`를 **0%까지 줄이면 안 됩니다.** 너무 사무적이라 거리감이 생깁니다.

### 실제 교정 결과 (참고 수치)

| | 수정 전 | 수정 후 |
|---|---:|---:|
| `~요` | 29회 (30%) | 6회 (6%) |
| `~다` / `~니다` | 6회 (6%) | 30회 (30%) |

---

## 🔴 절대 규칙: `~요` 연속 금지

**비율보다 연속이 문제입니다.** `~요`가 3번 이상 연달아 오면 무조건 고칩니다.

### 나쁜 예 (교정 전 실제 문장)

> 차가운 고객은 아직 우리를 잘 몰라**요**. 문제가 있는지도 크게 못 느낄 수 있어**요**.
> 가격표를 들이밀면 거절부터 나오는 게 당연해**요**. 저도 이런 분을 만난 적이 있어**요**.
> 저를 빤히 보더니 그러더라고**요**. 그때 그 눈빛은 아직도 기억나**요**.

`~요` 6연속. 읽다가 지칩니다.

### 좋은 예 (교정 후)

> 차가운 고객은 아직 우리를 **모릅니다.** 본인에게 문제가 있다는 것조차 느끼지 못할 수
> **있습니다.** 이런 분에게 처음부터 가격표를 들이밀면 거절이 먼저 **나옵니다.**
> 저도 예전에 영업을 하다가 이런 분을 **만났습니다.** 한참 설명하는데 저를 빤히 보더니
> 이렇게 **말했습니다.** "내가 그걸 왜 해야 되는데요?" 그때 그 눈빛은 아직도 **기억나요.**

단정한 문장 5개 뒤에 `~요` 하나. 마지막 한 줄에 온기가 살아납니다.

---

## `~요`를 쓰는 자리

아래 3가지에만 씁니다.

| 상황 | 예시 |
|---|---|
| **개인적 회상** | 그때 그 눈빛은 아직도 기억나**요**. |
| **공감 / 위로** | 억지로 끌면 파는 사람도 금방 지쳐**요**. |
| **가벼운 권유** | 그 온도에 맞춰 말을 걸어 보**세요**. |

그 외 설명·정의·근거·수치는 전부 `~입니다`로 씁니다.

---

## 🚫 쓰지 않는 표현

| 금지 | 이유 | 대체 |
|---|---|---|
| `~거든요` | 변명하는 느낌 | `~입니다` |
| `~고요` | 말끝을 흐림 | 문장을 끊는다 |
| `~잖아요` | 무례하게 들릴 수 있음 | `~입니다` |
| `~인데요` | 뒷말을 기대하게 만듦 | `~입니다` |
| `~답니다` | 옛스럽고 과함 | `~입니다` |
| `~십시오` | 지나치게 사무적 | `~세요` |
| `~해야 해요` | 훈계로 읽힘 | `~하는 편이 낫습니다` |

### `~십시오` 주의

한 번 `~십시오`로 통일했다가 **되돌렸습니다.** 너무 딱딱해서 상담사가 아니라
공문서처럼 읽혔습니다. 권유는 `~세요`가 적정선입니다.

---

## 제목 규칙

제목은 `~요`로 끝내지 않습니다. **단정하거나, 명사로 끊습니다.**

| Before | After |
|---|---|
| 고객 온도부터 보면 달라져**요** | 모든 고객에게 같은 말이 **통하지 않는 이유** |
| 바로 팔려고 하면 벽이 느껴져**요** | 바로 팔려고 하면 벽이 **생깁니다** |
| 후기 부탁도 타이밍이 중요해**요** | 후기 요청도 타이밍이 **전부입니다** |
| 크게 보면 이렇게 나뉘어**요** | 크게 세 단계로 **나뉩니다** |
| 홈페이지랑 SNS도 같은 눈으로 보면 돼**요** | 홈페이지와 SNS도 같은 기준으로 **봅니다** |

제목이 길면 뒷부분을 잘라냅니다.
`모든 고객에게 같은 말이 안 통하는 이유, 고객 온도부터 보면 달라져요` →
`모든 고객에게 같은 말이 통하지 않는 이유`

## ✅ 반드시 살릴 것

### 1인칭 실패담

이게 글의 **최고 자산**입니다. 남이 복제할 수 없습니다.

> 저도 예전에 영업을 하다가 이런 분을 만났습니다. 한참 설명하는데 저를 빤히 보더니
> 이렇게 말했습니다. **"내가 그걸 왜 해야 되는데요?"**

교정할 때 사례를 줄이지 않습니다. 오히려 **대사를 따로 떼어내 강조**합니다.

성공담보다 실패담이 신뢰를 만듭니다. `돌이켜보면 제가 너무 이르게 팔려고 했던 겁니다`
처럼 자기 잘못을 인정하는 문장을 아끼지 않습니다.

### 고객 실제 발화

`"내가 그걸 왜 해야 되는데요?"` 같은 날것의 말은 그대로 둡니다.
다듬으면 힘이 빠집니다.

## 리듬

문장 길이를 일부러 다르게 씁니다. 같은 길이가 이어지면 지루합니다.

**나쁨** — 전부 중간 길이
> 따뜻한 고객은 이미 자기 문제를 알고 해결책을 찾는 분들입니다. 홈페이지가 필요하다는
> 것도 어느 정도 압니다. 우리에게도 관심이 조금은 생긴 상태입니다.

**좋음** — 짧게 끊고 다시 늘림
> 장사를 하다 보면 모든 고객에게 비슷한 말을 하게 됩니다. 같은 안내문, 같은 설명,
> 같은 문의 권유. **그런데 결과는 매번 다릅니다.** 어떤 분과는 대화가 술술 풀리고,
> 어떤 분과는 첫마디부터 벽이 느껴집니다.

명사 나열(`같은 안내문, 같은 설명, 같은 문의 권유`)과 짧은 단문을 섞으면 리듬이 생깁니다.

## 표 / 카드 안의 문장

`status`, `label`, `caption` 같은 짧은 필드는 **명사형으로 끊습니다.**

| Before | After |
|---|---|
| 우리를 잘 모르고, 관심도 아직 적어**요** | 우리를 잘 모르고 관심도 아직 적은 **상태** |
| 이미 호감과 신뢰가 쌓여 있어**요** | 이미 호감과 신뢰가 쌓인 **상태** |

단, `example` 필드처럼 **실제 고객에게 하는 말**은 대화체를 유지합니다.

> "검색했을 때 정보가 비어 있으면, 문의 전에 그냥 나가시게 돼요."

## 작업 순서

1. 원본을 `.bak`으로 백업합니다.
2. `~요` 연속 구간을 찾습니다.
3. 설명·정의 문장을 `~입니다`로 바꿉니다.
4. 감정 대목 3~4곳에 `~요`를 남깁니다.
5. 제목을 단정형으로 바꿉니다.
6. `npx eslint src/data/blogPosts.js`
7. `npm run build`
8. 브라우저로 실제 렌더링 확인

### 비율 측정 스크립트

```bash
python - <<'PY'
import io,re
s=io.open('src/data/blogPosts.js',encoding='utf-8').read()
a=s.index("id: '대상글-slug"); b=s.index("id: '다음글-slug'")
t=s[a:b]
flat=[x or y for x,y in re.findall(r"'([^']{15,})'|\"([^\"]{15,})\"",t)]
sents=[]
for f in flat:
    for p in re.split(r'(?<=[.?!])\s+',f):
        if len(p.strip())>5: sents.append(p.strip())
yo=sum(1 for x in sents if re.search(r'(요|죠|어요|에요|예요)[.?!”"]?$',x))
da=sum(1 for x in sents if re.search(r'(다|니다)[.?!”"]?$',x))
print(f"문장 {len(sents)} | ~요 {yo} ({yo*100//len(sents)}%) | ~다 {da} ({da*100//len(sents)}%)")
PY
```

## PRODUCT.md와의 관계

`PRODUCT.md`의 원칙을 말투 차원에서 구현한 문서입니다.

- *"짧고 인간적인 한국어 문장"* → `~거든요`, `~고요` 제거로 문장을 끊는다
- *"바쁜 사장님이 빠르게 훑을 수 있게"* → `~요` 연속 제거로 리듬 확보
- *"밀어붙이는 에이전시처럼 들리지 않게"* → `~해야 해요` 금지
- *"차분한 파트너"* → 단정함 기본 + 감정 대목에만 온기
