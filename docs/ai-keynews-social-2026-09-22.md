## Naver Blog

오늘의 AI 키뉴스 | 2026년 9월 22일

최근 24~48시간 동안 공개된 AI 소식 가운데 일반 이용자들이 궁금해할 만한 변화 3건과 주요 업계 뉴스 2건을 골랐습니다. 제품 발표와 보도 내용은 공식 자료와 원보도를 기준으로 다시 확인했습니다.

1. Grok 4.7, GitHub Copilot에 추가…Pro 이상 순차 제공

GitHub는 9월 21일부터 xAI의 최신 추론 모델 Grok 4.7을 Copilot에 순차적으로 제공한다고 발표했습니다. Copilot Pro·Pro+·Max·Business·Enterprise 이용자는 VS Code, Copilot CLI, GitHub Copilot 앱과 주요 IDE의 모델 선택기에서 고를 수 있습니다. 모델 사용에는 제공업체 정가 기준의 사용량 기반 요금이 적용됩니다.

원문: https://github.blog/changelog/2026-09-21-grok-4-7-is-now-available-in-github-copilot/

2. 샤오미 MiMo-V2.6 오픈웨이트 공개…1M 토큰·멀티모달

샤오미는 MiMo-V2.6 Pro와 Flash의 가중치를 MIT 라이선스로 공개했습니다. 텍스트와 이미지, 영상, 음성을 함께 처리하고 최대 100만 토큰 문맥을 지원합니다. Hugging Face에는 Pro·Flash와 연구용 9B 증류 모델이 함께 올라왔습니다.

원문: https://huggingface.co/collections/XiaomiMiMo/mimo-v26

3. Kimi Code Desktop 출시…Mac·Windows에서 여러 작업 병렬 실행

Kimi Developers는 9월 21일 Kimi Code Desktop을 macOS와 Windows에 출시했습니다. 한 화면에서 여러 코딩 에이전트 작업을 동시에 실행하고, 시간이 오래 걸리는 작업도 진행 상태를 이어서 확인할 수 있습니다. 기존 개발 흐름에 데스크톱 앱을 붙여 사용하는 방식입니다.

원문: https://x.com/KimiDevs/status/2102009959051632935

4. Amazon, Meta Muse의 대신 쇼핑 차단

Amazon은 Meta의 개인 AI 에이전트 Muse가 이용자를 대신해 Amazon.com에서 상품을 찾고 구매하는 기능을 차단했습니다. Amazon은 Meta가 사전 승인을 받지 않았고 Muse가 에이전트임을 밝히지 않은 채 고객 정보에 접근할 수 있다는 우려를 제기했습니다. 현재 Muse로 Amazon 쇼핑을 시도하면 이용약관 위반 안내가 표시됩니다.

원문: https://techcrunch.com/2026/09/21/metas-ai-agent-has-been-blocked-from-using-amazon-com/

5. OpenAI, 외부 수학자 9명 참여 AI 수학 자문단 출범

OpenAI는 AI가 만든 새로운 수학 결과를 검토하고 공개 방식을 조언할 독립 자문단을 구성했습니다. 프린스턴 고등연구소가 운영을 지원하며 Timothy Gowers를 포함한 외부 수학자 9명이 참여합니다. 자문단은 결과의 정확성과 학술 기준, 연구자와 대중에게 알리는 방식을 살필 예정입니다.

원문: https://openai.com/index/advisory-group-on-mathematics-and-ai
