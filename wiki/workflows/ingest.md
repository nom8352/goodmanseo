# Ingest Workflow

Last updated: 2026-06-16

Use this when adding new source material into the GoodmanSEO wiki.

## Goal

Preserve evidence first, then synthesize. Do not overwrite the only copy of a source with a summary.

## Steps

1. Identify the source type: code, local doc, image asset, social copy, Notion reference, external page, or user-provided text.
2. Keep the raw source in its original location when possible.
3. If the source is new text from the user, save it under a stable project doc path before synthesizing.
4. Add a source note under `wiki/sources/` if it will be reused.
5. Add or update a concept note under `wiki/concepts/` only after source evidence is clear.
6. Update `wiki/log.md`.
7. If the source changes project status, also update `docs/current-status.md`.

## Stop Rule

If a source is missing, inaccessible, or ambiguous, record the uncertainty. Do not turn guesses into wiki claims.
